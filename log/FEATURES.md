# PixelVault Feature Matrix

| Area | Django edition |
|---|---|
| Home dashboard | Pinned work, today, counts, progress, quick actions |
| Ideas | Full metadata, prompts/content, tags, project relations, pinning |
| Projects | Full metadata, progress, local/server path, file tree, preview, URLs, pinning |
| Tasks | Status board, priority, type, energy, dates, time, duration, recurrence, dependencies, subtasks, tags, notes, pinning |
| Planner | Daily, weekly, calendar, inbox, drag/drop scheduling, overdue rollover, workload totals |
| Skills | Metadata, agents, use cases, Markdown editor, upload/write/download `.md`, pinning |
| Search | Global search + command palette + keyboard navigation |
| Highlights | Select page text, four colors, comments, persistent annotation library |
| Reports | Daily/weekly/monthly server-generated PNG + PDF |
| Settings | Profile, workspace, seven themes, light modes, accents, font size, density, accessibility, planner defaults, workspace-root security |
| Backup | JSON export/import |
| Authentication | First-run setup + Django login/logout |
| Admin | Django admin registrations for all core models |


## V5 experience layer

- Collapsible grouped sidebar with per-area counters and non-overlapping system footer
- Context-aware top bar and universal command/search trigger
- Today Mission briefing and interactive dashboard statistics
- Ideas grid/list modes, search, sorting, status filtering, and one-click conversion to a project
- Project overview metrics, search/sort, richer cards, and a full project workspace with file preview + next actions
- Task board/list modes, Today/Overdue/Pinned/Unscheduled smart filters, one-click complete/reopen, and status-specific quick creation
- Daily/weekly/monthly planner with sticky controls, workload cues, planning inbox, exact-hour quick add, and current-time marker
- Skills browser with category/pinned filters and Edit / Preview / Metadata tabs
- Reports preview with privacy seal, project momentum, top completions, and fast period switching
- Notes & Highlights search, page/color filtering, summary statistics, and source-page navigation
- Reworked forms with sectioned information architecture, larger controls, sticky save actions, and stronger validation hierarchy
- Responsive mobile bottom dock, larger text/hit targets, improved focus states, and redesigned login/setup experience
