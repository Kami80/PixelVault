# PixelVault V5.6 — Quick Access Sidebar UI

- Rebuilt the Quick Access area as a compact pixel-neumorphic panel.
- Added dedicated WEBP artwork for Pinned, Today, and Overdue actions.

- Added polished collapsed-sidebar behavior: icons stay usable while labels/counts hide cleanly.
